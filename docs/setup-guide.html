Setting up English SaathiFor Hikmat Foundation staff · once per MacBook, about 15 minutes · macOS 13 to 26

1

Install

  1. From Google Drive, download English-Saathi-….dmg (not the corretto file). If Drive can’t scan it for viruses, click Download anyway.
  2. Double-click the file. Drag English Saathi onto Applications. If macOS asks, type your Mac password.
  3. Eject the “English Saathi” disk (⏏ in Finder).
2

Open it the first time

macOS blocks it the first time. This is expected.

  1. Open Applications and double-click English Saathi. When macOS warns you, click Done (or Cancel).
  2. Open System Settings › Privacy & Security. Scroll down and click Open Anyway.
  3. Click Open Anyway (or Open) again. If asked, use Touch ID, or click Use Password… and type your Mac password.

Open Anyway shows for about an hour. If it isn’t there, double-click the app again.

3

Allow the microphone

When macOS asks to use the microphone, click Allow (OK on macOS 13).

Clicked Don’t Allow by mistake? Go to System Settings › Privacy & Security › Microphone, turn on English Saathi, then quit the app and open it again.

4

Clearer voices (optional, needs internet)

In System Settings › Accessibility, open Read & Speak (or Spoken Content), then System voice › ⓘ (or Manage Voices…). Download Rishi (Enhanced) (English (India)) and Lekha (Enhanced) (Hindi). Wait until both finish, then quit and reopen English Saathi. Settings (⌘,) › Voices shows their names.

5

Every day

  1. Each student picks their own card.
  2. Settings (⌘,): students, Add lessons…, speech model, microphone, voices.
  3. Results › Save as CSV… saves every attempt, for the evidence.
6

New versions

Quit English Saathi, drag the new one onto Applications and choose Replace. Students’ progress stays. Then do steps 2 and 3 again.

If macOS ever says the app is damaged, don’t use it. Ask for a new copy.

Keep the MacBook plugged in during sessions. Everything stays on this Mac.
