English Saathi: third-party software and data
==============================================

English Saathi includes the software and data listed below. Each keeps its
own licence. The list comes first, then the licence texts, then the NOTICE
texts that the Apache License asks to be passed on. This list is for the
Intel (x86_64) build of the app. It was checked against each project's own
files on 2026-10-22.

Two more files are part of these notices: onnxruntime-LICENSE.txt and
onnxruntime-ThirdPartyNotices.txt, ONNX Runtime's licence and third-party
notices, word for word (item 9). They are next to this file, in
English Saathi.app/Contents/app/resources/.

Paths below are inside English Saathi.app/Contents/.


1. Amazon Corretto 17.0.20.12.1 for macOS x64: the Java runtime (runtime/)
   and the app's launcher (MacOS/English Saathi)
   Licence: GNU General Public License, version 2, with the Classpath
   Exception. The licence, the exception and the runtime's own third-party
   notices are in runtime/Contents/Home/legal/. jlink keeps only the
   modules the app needs.
   Source code: corretto-17-17.0.20.12.1.tar.gz, in the same Google Drive
   folder as the English Saathi .dmg, and
   https://github.com/corretto/corretto-17, tag 17.0.20.12.1. The runtime
   was built from commit 2e3c08c; the tag adds only a change log entry.

     "Copyright (c) 2021 Xiaomi Corporation (authors: Fangjun Kuang)".
     Licence: Apache License 2.0. It includes a changed copy of libc++'s

   - OpenFst 1.8.5, https://github.com/csukuangfj/openfst (tag
     v1.8.5-2026-07-09): "Copyright 2005-2026 Google LLC." (its COPYING

     Licence: Apache License 2.0.

    (app/resources/models/)
    https://github.com/openai/whisper
    "Copyright (c) 2022 OpenAI". Licence: MIT (text below). Whisper's

    for sherpa-onnx:
    https://huggingface.co/csukuangfj/sherpa-onnx-whisper-tiny.en
    (commit d026532) and

    (commit d9533f6). Those pages state no licence of their own.
    Changed by English Saathi: in tiny.en-decoder.int8-embedding.onnx, the
    decoder's token embedding is stored as 8-bit integers, with one scale
    per token, instead of 32-bit floats. The rest of that file and the
    other model files are unchanged.
